# FOUR KINGS Command Room

スマートフォンから四天王AI（ChatGPT、Gemini、Grok、Copilot）の回答を個別に整理・保存するためのシンプルかつ最小限のWebアプリケーションです。

## アプリの目的
複数のAIサービス（ChatGPT, Gemini, Grok, Copilot）を利用する際、それぞれの回答やメモを1つの画面でまとめて個別に記録・整理することを目的としています。

## 使い方
1. ブラウザで `index.html` を開きます。
2. ChatGPT、Gemini、Grok、Copilot それぞれの入力欄にメモや回答テキストを入力します。
3. 入力した内容は自動的に保存されます。
4. ページを再読み込み・再訪問した際にも、保存されたテキストが復元されます。

## データ保存と注意点
- **保存先**: 本アプリのデータは、お使いの端末（ブラウザ）の `localStorage` 内にのみ保存されます。
- **自動送信・API連携なし**: 各AIへの自動送信機能や外部APIとの接続機能はありません。完全ローカルで動作します。
- **データ消失に関する注意**: ブラウザのキャッシュクリア、データ消去操作、または別のブラウザ・端末で開いた場合はテキストが保持・共有されません。重要なデータは別途手動でバックアップを行ってください。

## 動作環境
- モダンなWebブラウザ（Google Chrome, Safari, Firefox, Edge など）
- HTML / CSS / JavaScript のみ（外部ライブラリ・サーバー不要）
